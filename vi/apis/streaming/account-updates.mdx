## Channel

```text
order:Account:{accountId}
```

## Mô tả

Cập nhật tài khoản/danh mục realtime.

## WebSocket URL

```text
wss://api-data-hub.verolabs.co/connection/websocket
```

## Ví dụ subscribe

Các ví dụ bên dưới subscribe vào:

```text
order:Account:ACC123456
```

Thay `ACC123456` bằng ID tài khoản giao dịch thực tế.
