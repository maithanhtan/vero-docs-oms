## Channel

```text
mkt:{dataType}:{symbol}
```

## Mô tả

Dùng kênh này khi cần stream dữ liệu thị trường theo `dataType` và `symbol`. Tạo channel theo `mkt:${dataType}:${symbol}` rồi subscribe sau khi WebSocket kết nối thành công. Với depth, OHLCV và product info, ưu tiên các trang channel riêng vì các stream đó dùng định dạng channel cụ thể hơn.

## WebSocket URL

```text
wss://api-data-hub.verolabs.co/connection/websocket
```

## Ví dụ subscribe

Các ví dụ bên dưới subscribe vào:

```text
mkt:tradeLog:VN30F1M
```

Thay `tradeLog` hoặc `VN30F1M` bằng data type và mã giao dịch cần subscribe.

## Tham số channel

| Tham số | Kiểu | Mô tả | Giá trị |
|---|---|---|---|
| `dataType` | string | Loại dữ liệu thị trường của stream này. | enum: depth, productInfo, productStat, tradeLog |
| `symbol` | string | Mã giao dịch, ví dụ VN30F1M. | example: VN30F1M |

## Message

| Mục | Giá trị |
|---|---|
| Operation | `receiveGenericMarketData` |
| Tên | `GenericMarketData` |
| Payload | `GenericObject` |

## Payload schema

Payload là object JSON linh hoạt và có thể chứa thêm field theo publication thực tế.
