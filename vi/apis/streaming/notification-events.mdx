## Channel

```text
order:{notificationType}:{accountId}
```

## Mô tả

Thông báo giao dịch/tài khoản. Các topic hỗ trợ gồm Deposit, ForceClose, MarginCall và Withdraw.

## WebSocket URL

```text
wss://api-data-hub.verolabs.co/connection/websocket
```

## Ví dụ subscribe

Các ví dụ bên dưới subscribe vào:

```text
order:MarginCall:ACC123456
```

Thay `MarginCall` và `ACC123456` bằng topic thông báo và ID tài khoản cần subscribe.

## Tham số channel

| Tham số | Kiểu | Mô tả | Giá trị |
|---|---|---|---|
| `notificationType` | string | Loại topic thông báo được stream hỗ trợ. | enum: Deposit, ForceClose, MarginCall, Withdraw |
| `accountId` | string | ID tài khoản giao dịch. | - |
