## Channel

```text
mkt:productInfo:{symbol}-{boardId}
```

## Mô tả

Cập nhật product info/quote. `boardId` mặc định là `G1`.

## WebSocket URL

```text
wss://api-data-hub.verolabs.co/connection/websocket
```

## Ví dụ subscribe

Các ví dụ bên dưới subscribe vào:

```text
mkt:productInfo:VN30F1M-G1
```

Thay `VN30F1M` và `G1` bằng mã giao dịch và board id cần subscribe.

## Tham số channel

| Tham số | Kiểu | Mô tả | Giá trị |
|---|---|---|---|
| `symbol` | string | Mã giao dịch, ví dụ VN30F1M. | example: VN30F1M |
| `boardId` | string | Mã bảng giao dịch. Mặc định là G1. | default: G1<br />example: G1 |
