## Channel

```text
mkt:productInfo:{symbol}-{boardId}
```

## Mô tả

Cập nhật product info/quote. boardId mặc định hiện tại của ứng dụng là G1.

## WebSocket URL

```text
wss://streaming.verolabs.co/connection/websocket
```

## Tham số channel

| Tham số | Kiểu | Mô tả | Giá trị |
|---|---|---|---|
| `symbol` | string | Mã giao dịch, ví dụ VN30F1M. | example: VN30F1M |
| `boardId` | string | Mã bảng giao dịch. Ứng dụng mobile mặc định dùng G1. | default: G1<br />example: G1 |

## Message

| Mục | Giá trị |
|---|---|
| Operation | `receiveProductInfo` |
| Tên | `ProductInfo` |
| Payload | `SymbolInfo` |
| Handler | `StreamingService._handleMarketData` |
