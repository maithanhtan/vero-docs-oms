## Channel

```text
mkt:OhlcvDTO:{symbol}:{time}
```

## Mô tả

Cập nhật nến/OHLCV. Độ phân giải nến mặc định là 60 giây.

## WebSocket URL

```text
wss://streaming.verolabs.co/connection/websocket
```

## Ví dụ subscribe

Các ví dụ bên dưới subscribe vào:

```text
mkt:OhlcvDTO:VN30F1M:60
```

Thay `VN30F1M` và `60` bằng mã giao dịch và độ phân giải nến cần subscribe.

## Tham số channel

| Tham số | Kiểu | Mô tả | Giá trị |
|---|---|---|---|
| `symbol` | string | Mã giao dịch, ví dụ VN30F1M. | example: VN30F1M |
| `time` | integer | Độ phân giải nến tính bằng giây. Dùng 60 cho 1 phút và 86400 cho ngày. | default: 60<br />enum: 60, 86400 |

## Message

| Mục | Giá trị |
|---|---|
| Operation | `receiveOhlcv` |
| Tên | `Ohlcv` |
| Payload | `OhlcvBar` |

## Payload schema

| Field | Type | Notes |
|---|---|---|
| `unixTime` | integer (int64) | Unix timestamp. Cũng chấp nhận `time` như alias. |
| `time` | integer (int64) | Alias của `unixTime`. |
| `open` | number | - |
| `high` | number | - |
| `low` | number | - |
| `close` | number | - |
| `volume` | number | - |
