Trang này mô tả phần tối thiểu để gọi REST API và subscribe WebSocket streams.

## 1) Chuẩn bị thông tin xác thực

| Giá trị | Mô tả |
|---|---|
| `REST_URL` | `https://api-gw.verolabs.co/api/v1` |
| `AUTH_URL` | `https://api-gw.verolabs.co/api/authen` |
| `JWT` | Bearer token trả về từ luồng Ory login/session |
| `SESSION_TOKEN` | Ory session token dùng bởi một số native flow endpoint |
| `WS_URL` | `wss://streaming.verolabs.co/connection/websocket` |

<Info>
Không commit bearer token, session token hoặc account identifier vào source control.
</Info>

## 2) Gọi REST endpoint public

```bash
curl --request GET \
  --url "https://api-gw.verolabs.co/api/v1/health"
```

## 3) Gọi REST endpoint cần xác thực

```bash
export REST_URL="https://api-gw.verolabs.co/api/v1"
export JWT="<jwt>"

curl --request GET \
  --url "$REST_URL/users/accounts" \
  --header "Authorization: Bearer $JWT"
```

## 4) Subscribe streaming channel

Dùng Centrifugo WebSocket endpoint và subscribe channel pattern cần nhận:

```text
wss://streaming.verolabs.co/connection/websocket
mkt:depth:VN30F1M-G1
order:{accountId}
```

## Quy tắc quan trọng

| Quy tắc | Ghi chú |
|---|---|
| Giữ credential riêng tư | Không để lộ bearer hoặc session token trong log client hoặc tin nhắn hỗ trợ |
| Ghi log request ID | Giúp support truy vết request lỗi |
| Dùng filter theo tài liệu | Path và query param phải khớp với trang tham chiếu |
| Retry có kiểm soát | Dùng backoff cho lỗi tạm thời |
