## Kênh hỗ trợ

Nếu yêu cầu API lỗi hoặc dữ liệu trả về không như kỳ vọng, hãy chuẩn bị thông tin yêu cầu và liên hệ kênh hỗ trợ được cấp cho tài khoản của bạn.

  <Card title="Tích hợp API" icon="code">

## Thông tin cần gửi

| Thông tin | Ví dụ |
|---|---|
| Endpoint | Method và path đang gọi |
| Tham số truy vấn | Query string hoặc body JSON |
| Trạng thái HTTP | `200`, `400`, `401`, `404`, `429`, `503` |
| Nội dung phản hồi | Phản hồi JSON hoặc nội dung lỗi |
| Thời điểm request | UTC timestamp |
| Trường hợp sử dụng | Đồng bộ dữ liệu, quy trình đặt lệnh, dashboard hoặc công cụ vận hành |

<Info>
Không gửi bearer token, session token hoặc thông tin xác thực trong tin nhắn hỗ trợ.
</Info>
