## Độ phủ API

| Mục | Độ phủ |
|---|---|
| REST API | 47 HTTP operations |
| Streaming API | 8 WebSocket channel patterns |
| Xác thực | Truy cập REST và streaming cần bảo vệ |
| Quy trình giao dịch | Tài khoản, lệnh, khớp lệnh, lịch sử, rút tiền và tài khoản ngân hàng |
