## Channel

```text
order:{accountId}
```

## Description

Realtime order updates for an account.

## WebSocket URL

```text
wss://streaming.verolabs.co/connection/websocket
```

## Subscribe examples

The examples below subscribe to:

```text
order:ACC123456
```

Replace `ACC123456` with your trading account id.
