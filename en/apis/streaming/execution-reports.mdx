## Channel

```text
order:OrderExecutionReport:{connectionId}
```

## Description

Realtime order execution reports for the active connection_id.

## WebSocket URL

```text
wss://streaming.verolabs.co/connection/websocket
```

## Subscribe examples

The examples below subscribe to `order:OrderExecutionReport:{connectionId}`. Use the connection id returned by the streaming connection handshake.

The samples read `connectionId` from the connect reply and build the subscription channel after the connection is ready.
