## Channel

```text
order:{notificationType}:{accountId}
```

## Description

Trading/account notifications. Available notification topics are Deposit, ForceClose, MarginCall and Withdraw.

## WebSocket URL

```text
wss://api-data-hub.verolabs.co/connection/websocket
```

## Subscribe examples

The examples below subscribe to:

```text
order:MarginCall:ACC123456
```

Replace `MarginCall` and `ACC123456` with the notification topic and account id you need.

## Channel parameters

| Parameter | Type | Description | Values |
|---|---|---|---|
| `notificationType` | string | Notification topic type supported by the stream. | enum: Deposit, ForceClose, MarginCall, Withdraw |
| `accountId` | string | Trading account id. | - |
