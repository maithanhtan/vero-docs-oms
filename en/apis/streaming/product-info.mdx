## Channel

```text
mkt:productInfo:{symbol}-{boardId}
```

## Description

Product info/quote updates. Default `boardId` is `G1`.

## WebSocket URL

```text
wss://streaming.verolabs.co/connection/websocket
```

## Subscribe examples

The examples below subscribe to:

```text
mkt:productInfo:VN30F1M-G1
```

Replace `VN30F1M` and `G1` with the symbol and board id you need.

## Channel parameters

| Parameter | Type | Description | Values |
|---|---|---|---|
| `symbol` | string | Trading symbol, for example VN30F1M. | example: VN30F1M |
| `boardId` | string | Trading board id. Default is G1. | default: G1<br />example: G1 |
