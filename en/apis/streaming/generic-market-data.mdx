## Channel

```text
mkt:{dataType}:{symbol}
```

## Description

Use this channel when you need a market-data stream by `dataType` and `symbol`. Build the channel as `mkt:${dataType}:${symbol}` and subscribe after the WebSocket connection is open. For depth, OHLCV and product info, prefer the dedicated channel pages because those streams use more specific channel formats.

## WebSocket URL

```text
wss://api-data-hub.verolabs.co/connection/websocket
```

## Subscribe examples

The examples below subscribe to:

```text
mkt:tradeLog:VN30F1M
```

Replace `tradeLog` or `VN30F1M` with the data type and symbol you need.

## Channel parameters

| Parameter | Type | Description | Values |
|---|---|---|---|
| `dataType` | string | Market data type for this stream. | enum: depth, productInfo, productStat, tradeLog |
| `symbol` | string | Trading symbol, for example VN30F1M. | example: VN30F1M |

## Message

| Item | Value |
|---|---|
| Operation | `receiveGenericMarketData` |
| Name | `GenericMarketData` |
| Payload | `GenericObject` |

## Payload schema

The payload is a flexible JSON object and may include additional fields from the live publication.
