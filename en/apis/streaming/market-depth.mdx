## Channel

```text
mkt:depth:{symbol}-{boardId}
```

## Description

Order-book depth updates. Default `boardId` is `G1`.

## WebSocket URL

```text
wss://api-data-hub.verolabs.co/connection/websocket
```

## Subscribe examples

The examples below subscribe to:

```text
mkt:depth:VN30F1M-G1
```

Replace `VN30F1M` and `G1` with the symbol and board id you need.

## Channel parameters

| Parameter | Type | Description | Values |
|---|---|---|---|
| `symbol` | string | Trading symbol, for example VN30F1M. | example: VN30F1M |
| `boardId` | string | Trading board id. Default is G1. | default: G1<br />example: G1 |

## Message

| Item | Value |
|---|---|
| Operation | `receiveMarketDepth` |
| Name | `MarketDepth` |
| Payload | `PriceDepth` |

## Payload schema

| Field | Type | Notes |
|---|---|---|
| `seq` | number | - |
| `time` | number | - |
| `symbol` | string | - |
| `boardID` | string | - |
| `bidPriceDepth` | array&lt;PriceLevel&gt; | - |
| `askPriceDepth` | array&lt;PriceLevel&gt; | - |
