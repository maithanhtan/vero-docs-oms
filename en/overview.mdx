Vero OMS API helps applications integrate with Vero order management workflows through REST/JSON and Centrifugo WebSocket streams. The REST reference is generated from `openapi.json`; the streaming reference is generated from `asyncapi.json`.

<CardGroup cols={4}>
  <Card title="Authentication" icon="key">
    Use Ory native flows, `X-Session-Token` and bearer JWT credentials.
  </Card>
  <Card title="Trading" icon="arrow-right-arrow-left">
    Work with accounts, orders, trades, history, withdrawals and bank accounts.
  </Card>
  <Card title="Market Data" icon="chart-line">
    Fetch watchlists, symbol search, product master data and OHLCV history.
  </Card>
  <Card title="Streaming" icon="tower-broadcast">
    Subscribe to market, order, account and notification channels over WebSocket.
  </Card>
</CardGroup>
